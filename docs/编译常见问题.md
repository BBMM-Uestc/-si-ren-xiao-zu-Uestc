# 编译常见问题速查（VS2022 + wxWidgets 3.2.2.1）

> 本工程的实际配置：x64 / Debug / Unicode / 静态库 / `/MDd` / C++17 / `/utf-8`
> wxWidgets 目录：`C:\wxWidgets-3.2.2.1\lib\vc_x64_lib`（库名形如 `wxbase32ud.lib`、`wxpngd.lib`）

---

## 一、先按错误前缀分三类

| 前缀 | 阶段 | 说明 |
|---|---|---|
| `C####` / `C####` | 编译 | 源文件、头文件、宏、语言标准 |
| `LNK####` | 链接 | 库路径、库名、CRT、符号 |
| `MSB####` | 构建系统 | 工具集、SDK、文件占用、目录权限 |

**定位顺序**：先解决编译错误（C），再解决链接错误（LNK），最后才是 MSB（往往是环境）。

---

## 二、最常见 12 个问题

### 1. `C1083: 无法打开包括文件: "wx/wx.h"`
- **原因**：找不到 wxWidgets 头文件目录，或 `WX_ROOT` 指错。
- **解决**：把 [MiniLogisim.vcxproj](../MiniLogisim.vcxproj) 里的 `WX_ROOT` 改成你的实际路径
  （默认 `C:\wxWidgets-3.2.2.1`），或设同名环境变量。
- **注意**：包含路径有两个，别只加一个：
  `$(WX_ROOT)\include` 和 `$(WX_LIBDIR)\mswud`（`setup.h` 在后者里）。

### 2. `LNK1104: 无法打开文件 "wxpngud.lib"`（或 `wxregexd.lib` 之类）
- **原因**：**库名后缀搞混了**。wxWidgets 自身的库是 `ud`（Unicode+Debug），
  第三方库只有 `d`：
  - ✅ `wxbase32ud.lib`、`wxmsw32ud_core.lib`、`wxmsw32ud_adv.lib`
  - ✅ `wxpngd.lib`、`wxjpegd.lib`、`wxtiffd.lib`、`wxzlibd.lib`、`wxexpatd.lib`
- **解决**：工程里用两个变量区分——`WX_SUFFIX=ud`（wx 自身）、`WX_CSFX=d`（第三方）。
  手工配置时别统一加 `ud`。

### 3. `LNK1104: 无法打开文件 "…\逻辑电路仿真器.exe"`
- **原因**：**程序还在运行**，exe 被占用。
- **解决**：关掉正在运行的窗口（或任务管理器结束进程）再编译。
  这也是"改了代码但行为没变"的最常见原因——你跑的是旧 exe。

### 4. `LNK2038: 检测到 "RuntimeLibrary" 的不匹配: 值 "MTd_StaticDebug" 与 "MDd_DynamicDebug" 不匹配`
- **原因**：工程的运行库和 wxWidgets 库不一致。本机 wx 库是用 **`/MDd`（动态调试 CRT）** 编译的。
- **解决**：工程属性 → C/C++ → 代码生成 → 运行库 = **多线程调试 DLL (/MDd)**。

### 5. 中文乱码（编译能过，界面全是问号/方块）或 `C4819` 警告
- **原因**：源文件是 UTF-8，但 MSVC 默认按系统代码页（GBK）解析。
- **解决**：
  1. 工程属性 → C/C++ → 命令行 → 附加选项加 **`/utf-8`**（本工程已加）；
  2. 所有含中文的字符串字面量用 **`wxT("…")`**（宽字符），不要写裸 `"中文"`。
  两步缺一不可：只加 `/utf-8` 而用窄字符串，运行时仍会乱码。

### 6. `MSB8020: 无法找到 v143 的生成工具`
- **原因**：没装 C++ 工作负载或工具集。
- **解决**：VS Installer → 修改 → 勾选「使用 C++ 的桌面开发」。

### 7. `MSB8036: 找不到 Windows SDK 版本 10.0.xxxxx`
- **原因**：`WindowsTargetPlatformVersion` 指向了没安装的 SDK。
- **解决**：把 vcxproj 里改成 `10.0`（自动选最新），或安装对应 SDK。

### 8. `LNK1112: 模块计算机类型 "x86" 与目标计算机类型 "x64" 冲突`
- **原因**：配置选成了 x86，而库是 x64。
- **解决**：VS 工具条上选 **Debug | x64**。

### 9. `LNK2019: 无法解析的外部符号`（一堆 wx 函数）
- **原因**：库清单缺项，常见三种：
  1. 只加了 `_core` 没加 `wxbase32ud.lib`；
  2. 少了系统库：`comctl32.lib rpcrt4.lib shlwapi.lib version.lib ws2_32.lib wininet.lib oleacc.lib uxtheme.lib winmm.lib`；
  3. 用的是 **DLL 版** wxWidgets（`vc_x64_dll` 目录），却按静态方式链接。
- **解决**：确认 `WX_LIBDIR` 指向 `lib\vc_x64_lib`（静态），并对照工程里的 `AdditionalDependencies`。

### 10. `MSB3491: 未能向文件 "…\MiniLogisim.lastbuildstate" 写入行`
- **原因**：`obj` / `bin` 目录**不可写**。常见于：
  放在 OneDrive 同步目录、被杀毒软件锁、文件夹权限异常、或从别的账户拷贝来的目录。
- **解决**（任选）：
  - 把工程复制到普通目录（如 `D:\logic-sim`）重新打开；
  - 或者改输出目录：项目属性 → 常规 → 输出目录/中间目录 指到 `%TEMP%` 下；
  - 或以管理员身份运行 VS。

### 11. 莫名其妙的语法错误：`语法错误:"="` / `"&&"`，位置看起来完全正确
- **原因**：**撞上了 Windows 的遗留宏**。`windows.h` 里 `near`、`far`、`small`、`interface`、`min`、`max` 等都是宏，
  用作变量名会被展开成空或表达式。
- **解决**：变量改名（本项目就把 `near` 改成了 `nearComp`）；
  需要 `min/max` 时加 `#define NOMINMAX` 并写 `(std::min)(a,b)`。

### 12. 资源编译失败 / 控件是"Windows 98 风格"
- **原因**：`res\app.rc` 没编进去，或缺 `wx/msw/wx.rc`（它负责引入 comctl32 v6 清单）。
- **解决**：确认 vcxproj 里有
  `<ResourceCompile Include="res\app.rc" />`，
  且 RC 的附加包含目录含 `$(WX_ROOT)\include`。

## 三、其他容易忽略的坑

| 现象 | 原因 | 解决 |
|---|---|---|
| 改了代码但行为没变 | 跑的是旧 exe / 增量编译缓存 | 关掉程序、清理解决方案、删 `obj` `bin` 重编 |
| 改了 `TargetName` 后有两个 exe | 旧名 exe 残留 | 手动删掉 `bin\Debug\MiniLogisim.exe` |
| 打开 .sln 提示"找不到项目" | 文件夹被移动/改名 | 重新添加项目，或用新路径打开 |
| Release 配置链接失败 | 本机 wxWidgets 只编译了 Debug 静态库 | 先用 Debug 演示；要 Release 需自行编译 wx Release 库 |
| 编译很慢 | 单进程编译 | 工程已开 `/MP`；或关闭杀软实时扫描 `obj` |
| 首次打开提示"重定向项目" | SDK/工具集版本不一致 | 选"取消"或重定向到已安装的 SDK，别升到不存在的版本 |

## 四、最省事的三条路（按优先级）

1. **直接运行已编译好的程序**：`bin\Debug\逻辑电路仿真器.exe`（演示场景够用，绕开所有编译问题）。
2. **用脚本编译**：命令行执行 `build.bat`（会自动找 MSBuild、检查 `WX_ROOT`、报明确的错）。
3. **在 VS 里编译**：打开 `MiniLogisim.sln` → 选 **Debug | x64** → `F7`。

## 五、30 秒自检清单（编译失败时按这个顺序查）

- [ ] 平台选的是 **x64**？（不是 x86 / Any CPU）
- [ ] `WX_ROOT` 指向的目录里 `include\wx\wx.h` 存在吗？
- [ ] `WX_LIBDIR` 下有 `wxbase32ud.lib` 吗？（有 → 静态 Debug 库齐全）
- [ ] 运行库是 **/MDd** 吗？
- [ ] 程序是不是还在运行（exe 被占用）？
- [ ] `obj`、`bin` 可写吗？（在 OneDrive 里就换目录）
- [ ] 报错是 `C`（代码）、`LNK`（库）、还是 `MSB`（环境）？
